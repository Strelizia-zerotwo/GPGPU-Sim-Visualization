按照缺少的环节准备环境

WSL 首次安装需要 Windows 管理员权限和可能的重启；后续实验在桌面窗口中操作。

01

安装 WSL 与 Ubuntu

在 Windows 开始菜单找到 PowerShell，右键“以管理员身份运行”，执行下面的命令。 

wsl --install -d Ubuntu

按提示重启 Windows。第一次打开 Ubuntu 时，创建 Linux 用户名和密码。

02

准备 Python 和编译依赖

打开 Ubuntu 终端，执行下面的命令。sudo 要求输入刚创建的 Linux 用户密码，输入时不会显示字符。 

sudo apt-get update
sudo apt-get install -y python3 git build-essential cmake bison flex zlib1g-dev libgl1-mesa-dev
03

选择 CUDA Toolkit

已有 CUDA 时，自动检测会列出版本与路径。首次安装时，按 NVIDIA 的 Ubuntu / WSL 指引安装 Toolkit，再回到软件重新检测。 

/usr/local/cuda-12.8/bin/nvcc --version

推荐先使用本项目已经验证的 CUDA 12.8。选择 Toolkit 安装方式，保留其他项目正在使用的 CUDA 版本。

04

部署模拟器并下载程序

回到“环境设置”，确认 Linux 部署目录和 CUDA 路径，点击“一键下载并编译”。完成后进入 PolyBench 商店，选择需要的程序下载。

先用单个 GEMM、规模 8、重复 1 次验证运行；确认通过后再增加规模与并发。
